# DH Climate Ingress · Operations v1 (0.2.1)

## Назначение

Первая версия — инженерный read-only Operations. Сначала экран и навигация,
затем развитие API и Configuration. Приложение показывает только данные
существующего Climate Runtime и настроенные объекты.

Нет в 0.2.1: Configuration/Apply, собственного конфигурационного манифеста,
реестра физических активов и каналов Dingtian, HA Areas, новых
управляющих команд или дополнительных MQTT Discovery entities.
Эти направления остаются в roadmap.

## Workbench

- Activity Bar: System, Weather, Home, Resources, Season, Rooms.
- Контекстная левая панель: комнаты и их исполнители; ресурсы и источники.
- Центральная панель: актуальные состояния, Problems, переходы к устройствам.
- Inspector: источник и HA entity_id с копированием.
- Статусная строка: версия приложения и read-only.
- Узкие экраны: дополнительные панели скрываются.

Состояния получены непосредственно из Outdoor/Room Engine, HA StateCache,
Health, Problems, Demand. Никакого второго алгоритма в браузере нет.

## HTTP и безопасность

GET /api/snapshot — read-only текущая проекция, schema_version=1.
GET /api/events — SSE при изменении проекции плюс heartbeat.
Статика: /, /app.js, /style.css, /i18n/en.json, /i18n/ru.json.

Другие HTTP методы отвергаются 405; неизвестные пути — 404.
Сервер принимает запросы только от Supervisor 172.30.32.2.
Аутентификацию выполняет HAOS Ingress. Порт 8099 наружу не публикуется,
панель доступна администраторам (panel_admin: true).
Токены Supervisor/MQTT и содержимое /data не передаются в браузер.

При потере соединения HA существование комнат и оборудования сохраняется,
но текущие измерения становятся неизвестными. Ingress не считает
switch.on физическим подтверждением открытого клапана.

## Локализация и комнаты

Есть словари ru/en для интерфейса с выбором по браузеру и ручным
переключением. Для других языков предусмотрено расширение словарей.

Текущие Room ID/name читаются из существующего конфигурационного контракта.
Обязательный английский Room.name, локализованные имена помещений и
необязательная информационная связь с HA Area — будущий этап схемы,
без опасной автоматической миграции. В Operations v1 нет зависимости
от Home Assistant Areas.

## Приёмка

- unittest на read-only HTTP, защиту от не-Supervisor клиентов,
  SSE, offline и проекцию Runtime.
- Полный регрессионный suite существующего Climate App.
- До production отдельно проверить на HAOS: открытие Ingress iframe,
  работу относительных путей, SSE, потерю связи с HA, ноль комнат,
  отсутствующие ресурсы, мобильную ширину и повторный старт.

Никаких прямых физических live-коммутаций на этапе UI-проверки.

## Roadmap за пределами v1

1. Физические конечные устройства, Equipment/Channels/HA bindings,
   двухсторонняя трассировка по известным связям.
2. Технический ID + английское имя + переводы; HA Area — необязательная
   информационная связь, не участвующая в жизненном цикле DH Room.
3. Configuration на базе проверенного интерфейса Operations.
4. Единый persisted topology manifest в /data c draft, diff,
   validation, apply/rollback, без конкуренции с SQLite-уставками.
